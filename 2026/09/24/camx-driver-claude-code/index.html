项目介绍：CamX 摄像头传感器驱动智能生成与调优助手

发表于2026-09-24|更新于2026-09-24|项目介绍
|总字数:853|阅读时长:2分钟|浏览量:

基于 Claude Code 打造的高通 CamX 平台摄像头传感器驱动全生命周期辅助工具，用 RAG + 多模态 LLM 自动生成驱动配置，并配套设备部署、测试验证、ISP 调优的完整工具链。

项目背景

高通 CamX 平台的摄像头传感器驱动开发，传统流程依赖工程师手动查阅传感器数据手册（PDF），逐字段抄录寄存器配置到驱动 XML 中，过程繁琐且容易出错。本项目基于 Claude Code 打造了一套面向”驱动生成 → 设备部署 → 测试验证 → ISP 调优 → 结果比对”五阶段流程的智能辅助工具，目前驱动生成阶段已完成，设备部署、测试验证与调优阶段部分完成，结果比对阶段规划中。

核心工作

1. RAG 驱动的传感器驱动 XML 自动生成引擎

以 YAML 声明式规范定义字段提取策略，包括 const（常量）、retrieve（检索）、compute（计算）、derive（派生）、power_up/power_down（上下电时序）、power_from_pdf（从 PDF 图像解析时序）共 7 种类型。引擎通过向量检索（Chroma）+ LLM 从传感器数据手册 PDF 中精确抽取寄存器配置，合并生成符合 CamX 规范的驱动 XML。

针对数据手册中的时序图等非结构化图像信息，引入多模态 LLM 直接解析上下电时序，弥补了纯文本 RAG 无法覆盖的场景。

2. Skill 化的工程能力组织

基于 Claude Code 的 Skills 机制，将功能拆分为 47 个独立技能模块，覆盖 PDF 解析、ADB 设备通信、PDAF 对焦扫描、AE 曲线分析、黑电平均匀性、坏点检测、暗电流噪声、帧时序、陀螺仪 EIS 等 10+ 项自动化测试分析能力，形成”按需求自动匹配对应工具链”的 Agent 化工程组织方式。

3. 驱动全流程部署链路

包括远程交叉编译、ADB 推送、权限配置、服务重启等自动化步骤，并配套设备端健康检测（模组探测、数据流校验、OTP 校验），减少人工介入。

4. 桌面调试工具

独立开发了一款约 1.7 万行代码的 tkinter + matplotlib 桌面调试工具，支持 Logcat/UMD/KMD 日志实时解析与 PDAF 对焦曲线可视化，并通过 PyInstaller 打包为约 35MB 的可执行程序，供产线与测试团队直接使用，无需搭建 Python 环境。

项目规模

  • Python 代码总量约 3.8 万行
  • 47 个功能模块（Skill）
  • 109 次迭代提交
  • PDF 表格解析支持并行 / 远程 worker 加速

技术栈

Python、RAG（Chroma 向量库）、多模态 LLM、Camelot PDF 解析、tkinter / matplotlib、numpy / torch、ADB / SSH 远程设备控制。

技术亮点

  1. 用声明式 DSL 抽象了 7 种异构字段提取策略，统一处理结构化文本与图像时序信息的自动解析；
  2. 将 RAG 从通用问答场景落地到硬件寄存器语义这一垂直工程领域，实现驱动配置生成的高准确率自动化；
  3. 大规模 GUI 工具与嵌入式日志解析器结合，支撑实时可视化调试；
  4. 完整的软硬协同调优闭环设计，为后续硬件自动化（机械臂、灯箱、图卡台）预留了扩展空间。
